# Frontend Environment Setup

This guide covers the tools and setup steps for the React frontend project described in the main roadmap.

---

## Install the tools needed for frontend development

### Visual Studio Code

Download: <https://code.visualstudio.com>

Purpose: code editor for frontend development.

### Node.js and npm

Download Node.js from <https://nodejs.org>. npm is included with Node.js.

Verify the installations:

```bash
node -v
npm -v
```

Node.js runs JavaScript outside the browser. npm manages project dependencies, similar to Maven or Gradle in Java projects.

### pnpm

Install and verify pnpm:

```bash
npm install --global pnpm
pnpm -v
```

pnpm is an alternative package manager; it is the recommended choice for this project.

### Git

Download Git from <https://git-scm.com> and verify it:

```bash
git --version
```

### Outcome

The development environment is ready.
